# 복잡한 구현 문제 팁

상어 문제(삼성 문제집에 있는 빡구현 시리즈)들을 풀면서 깨달은 것들을 정리해놓으려고 한다.

### 1. 쓸 데 없는 최적화 하지 않기

구현 문제를 풀다보면 배열을 반복 순회해서 뭔가 확인해야 하는 경우가 많다. 이런 과정들을 자료구조에 캐싱해서 효율성을 높이고 싶은 욕구가 생기게 되는데, 좀 비효율적이더라도 가능한 단순하게 구현하는 것이 좋다.

```c++
// 아래처럼 index to pos 배열 대신 매번 순회해서 찾아오는 함수를 사용하는 것이 확실하다
pr shark_pos[16];
for (int num = 1; num <= 16; num++)
    auto [r, c] = shark_pos[num];

// 단순한 순회 함수
pr find_pos(int idx, const vector<vector<fish>>& board) {
    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < 4; j++) {
            if (board[i][j].number == idx)
                return {i, j};
        }
    }
    return {-1, -1};
}

for (int num = 1; num <= 16; num++)
    auto [r, c] = find_pos(num, board);
```

꼭 써야 한다면 일단 가장 단순한 형태의 함수로 구현해놓고, 코드가 제대로 작동하는 것을 확인하고 나중에 개선시키는 것이 가장 안전하다.

[19236번 청소년 상어](https://www.acmicpc.net/problem/19236) 문제를 풀 때 배열을 사용하여 계속 안 풀리던 것을 단순한 함수로 변경했더니 바로 풀린 경험이 있다.

```c++
// 캐싱 자료구조 대신 순회 함수로 구현한 다른 예시

bool is_duplicate(int i, int j) {
    for (auto [r, c] : clouds) {
        if (i == r && j == c)
            return true;
    }
    return false;
}

// 매번 순회해서 찾는 모습이 불편하지만 단순한 방식이 구현이 빠르고 정확하므로 익숙해져야 한다.
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (board[i][j] >= 2 && !is_duplicate(i, j)) {
            board[i][j] -= 2;
            new_clouds.emplace_back(i, j);
        }
    }
}
```

### 2. 인덱스는 무조건 0부터
- 위치 인덱스, 방향 배열 인덱스, 문제에서 제시하는 개념의 번호 등 가능하면 전부 0부터 시작하도록 입력 부분에서 미리 처리한다.
- 0부터 시작해야 % 기호를 편하게 사용할 수 있고, 실수를 방지할 수 있다
- 어쩔 수 없이 1부터 시작해야 하는 경우 주석으로 확실하게 기록한다

### 3. 이동 및 방향 저장 관련
- `using pr = pair<int,int>;`
- `const pr dirs[] = { ... };`
- 위의 구조를 고정으로 한다
- 방향 인덱스 변수는 `d` 또는 `dir`을 사용한다

### 4. 함수 및 변수 이름은 적당히 구체적으로
- 문제에서 제시하는 개념을 가능한 그대로 옮길 수 있도록 한다
- 여러 동작을 지시할 때 각각의 동작을 함수로 분리하는 것이 정리에 도움이 된다

### 5. `std::move()` 적극 활용하기
이동 구현을 하다보면 사본 배열을 만들어야 하는 경우가 생기는데, 이때 `new_board`를 만들어 결과를 저장하고, 모든 동작이 끝난 후 `board = std::move(new_board);`를 해주면 효율성도 챙기고 개념적으로도 이해하기가 좋다.

### 6. 쉬운 이동 구현

만약 d방향으로 s만큼 움직여야 하고, 맵 밖으로 이동하면 반대쪽으로 나오는 경우 아래와 같은 템플릿을 사용하면 간단하게 구현할 수 있다

```C++
inline int clamp(int target) {
    if (target < 0)
        return target + n;
    return target;
}

int nr = clamp((r + dirs[d].first * s) % n);
int nc = clamp((c + dirs[d].second * s) % n);
```
C++에서 음수 x에 %를 사용하면, x를 양수로 바꾸고 %를 취한 뒤 다시 음수로 바꾼 것과 동일하게 작동한다. 따라서 위와 같은 함수를 사용하면 `dirs[d]`가 음수여도 원하는 결과를 얻을 수 있다.

파이썬은 처리 방식이 달라 `clamp`를 구현하지 않아도 같은 결과가 나온다

> - C++에서 `-48 % 50`를 실행하면 `-48`이 나옴
> - 파이썬에서 `-48 % 50`를 실행하면 `2`가 나옴

좀 더 고민하면 더 이쁘게 만들 수 있을 것 같긴한데 일단 사용하기엔 나쁘지 않은 것 같다.
